# PRAMAAN-AI — Start Here

## Open in Antigravity
1. Extract this folder somewhere easy to find, such as your Desktop.
2. In Antigravity, choose **Open Folder** and select the `pramaan-ai` folder itself (not `docs` and not `docs/reference`).
3. Confirm `AGENTS.md` is directly inside the project root.
4. Confirm both reference files are inside `docs/reference/`.
5. Open `AGENTS.md` and read it. Then start with Prompt 1 in `docs/PRAMAAN_AI_Antigravity_SIH_Playbook.md`.

## Folder layout
- `AGENTS.md` — persistent project instructions for the coding agent.
- `docs/PRAMAAN_AI_Antigravity_SIH_Playbook.md` — staged build prompts and quality gates.
- `docs/reference/SIH Winning Pack PRAMAAN-AI for AICTE Approvals.pdf` — full planning pack.
- `docs/reference/SIH26261_problem_statement.md` — the problem statement text to use as a reference.

## Important
Prompt 1 is planning-only. Review its specifications before asking the agent to code. Use one implementation prompt at a time and test each milestone before continuing.
